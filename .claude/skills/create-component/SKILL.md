# Create a component

1. Read `client/CLAUDE.md` and `.claude/rules/client/components.md` first (they may not load on their own before the file exists).
2. Decide whether the component is admin-only; if so it goes under `admin/` in both folders.
3. Create `src/components/X.jsx` and `src/CSS/components/X.module.css` following the rules.
4. Run the "Before finishing" checklists from both files.
